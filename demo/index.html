Virtual hardware workbench

This is an executable software model, not physical wiring. The existing scenario definitions map events to fixed virtual resources (I2C0, SPI0, UART0); connect/disconnect changes are passed to the C CLI. A disconnected link is rejected by the virtual adapter before event admission mutates runtime state.
