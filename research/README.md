# Research Evidence

This directory stores the evidence base used to select and validate the project topic.

## Required evidence classes

- `papers.csv` — academic papers and proceedings
- `patents.csv` — patents and patent applications
- `products.md` — commercial/industrial solutions
- `open_source.md` — relevant open-source implementations
- `standards.md` — standards/specifications where applicable
- `gap_analysis.md` — comparison and identified gaps

## Evidence discipline

Every important claim should be traceable to a source.

For each source, record:

- exact title;
- authors/assignee;
- publication/application date;
- persistent identifier or official URL;
- what the source actually demonstrates;
- relevance to the candidate;
- limitations;
- similarity to our proposed mechanism;
- whether it weakens or strengthens the novelty hypothesis.

Search results are leads, not evidence by themselves.
